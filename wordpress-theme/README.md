# Agent Harness Studio — WordPress Theme Package

This directory contains the standalone **Custom WordPress Theme** for the **Founder Manifesto & Agent Harness Portfolio**.

---

## 📦 How To Install On Any WordPress Site

1. **Compress the Theme**:
   Zip all files in the `wordpress-theme/` folder into a single ZIP archive named `harness-studio-theme.zip`.

2. **Upload to WordPress**:
   - Log into your WordPress Admin Dashboard (`/wp-admin`).
   - Go to **Appearance** → **Themes**.
   - Click **Add New Theme** → **Upload Theme**.
   - Select `harness-studio-theme.zip` and click **Install Now**.
   - Click **Activate**.

3. **Verify Interactive Features**:
   - The theme automatically enqueues Google Fonts (*Newsreader*, *Outfit*, *Inter*, *Fira Code*), CSS styles, and JavaScript controllers.
   - Interactive widgets (WhatsApp Simulator, DSO Calculator, Rule Inspector, Booking Modal) will be live out of the box!
